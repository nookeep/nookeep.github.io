정보와 이용 목적

NooKeep Android 앱의 개인 기록은 계정 없이 사용할 수 있습니다. 계정·친구·편지 관련 정보는 해당 기능을 이용할 때 처리합니다.

기기 내 기록
촬영·선택한 사진은 피사체 분리에 사용합니다. 스티커·상자의 날짜와 한 줄·배치·작성 중인 편지·앱 설정은 기기 내 앱 전용 공간에 보관합니다. 친구에게 붙인 별명도 기기에만 저장하며 상대에게 전송하지 않습니다.
계정과 친구
계정 식별자·Google 로그인에서 제공되는 이메일과 기본 프로필·닉네임·거위 외형·친구 코드·요청·관계·차단 상태·규칙 동의 정보를 인증과 친구 기능에 사용합니다. 연락처 목록은 수집하지 않습니다.
주고받는 편지
보내기를 선택한 편지의 완성 이미지와 썸네일·발신자·수신자·전달 및 읽음 상태를 저장합니다. 입력한 글과 배치한 스티커는 완성 이미지에 포함되며, 본문 텍스트를 서버에 따로 저장하지 않습니다. 개인 상자 전체나 미전송 초안을 자동 업로드하지 않습니다.
신고와 운영 조치
신고자와 대상의 계정 식별자·신고 사유·접수 시각·조치와 열람 기록을 처리합니다. 편지 신고에는 선택한 편지의 이미지 사본이 포함됩니다. 위반으로 삭제한 이미지의 해시는 같은 파일의 재전송 방지에 사용합니다.
문의
이메일로 보내신 연락처와 문의 내용을 요청 확인·응대에 사용합니다. 비밀번호·인증번호·신분증은 보내지 마세요.
과도한 요청 방지
계정 식별자·요청 횟수·시각을 처리해 과도한 요청을 제한합니다.

서비스와 처리 위치

Google ML Kit

Google ML Kit의 피사체 분리는 기기에서 수행하며, 이 처리를 위해 사진을 Google 서버로 보내지 않습니다. Google은 모델 배포·진단·사용 현황 분석을 위해 기기·앱 정보, 기기 또는 설치 식별자, 성능·오류 정보와 이미지 형식·크기 등의 처리 정보를 수집합니다. 자세한 항목은 ML Kit 데이터 안내에서 확인할 수 있습니다.

Google Firebase

계정과 친구·편지 기능에는 Google Firebase를 사용합니다. Firebase Authentication은 인증 정보를 미국에서 처리하며, 인증 보안과 부정 사용 방지를 위해 IP 주소와 사용자 에이전트 정보를 처리합니다. Firebase의 저장·처리 위치는 서비스마다 다르므로, 데이터베이스를 국내에 두더라도 모든 정보가 국내에서 처리되는 것은 아닙니다. 자세한 내용은 Firebase 개인정보 안내를 참고하세요.

오류·성능 진단

현재 Crashlytics·Performance Monitoring의 원격 수집은 기본 비활성 상태입니다. 활성화할 경우 수집 항목·목적·보관 기간·국외 이전을 먼저 안내하고 필요한 동의 절차를 마련합니다. NooKeep은 광고 추적이나 Google Analytics를 사용하지 않습니다. 앞서 설명한 ML Kit 제공자의 진단 처리는 이 설정과 별개입니다.

공유와 접근

편지는 지정한 상대와 주고받습니다. 친구를 삭제하면 다시 친구가 되기 전까지 새 편지를 보낼 수 없고, 차단하면 새 친구 요청도 막습니다. 어느 경우에도 이미 받은 편지는 보존합니다. 발신자가 접수된 편지를 회수하는 기능은 없습니다. 신고자의 신원을 신고 대상에게 공개하지 않습니다.

권한을 가진 담당자는 접수된 신고 자료를 운영 검토에 사용하며, 자료 열람과 조치를 기록합니다. 일반 편지 전체를 열람하는 화면은 제공하지 않습니다. 편지는 종단 간 암호화 방식으로 처리되지 않습니다.

이미지 내보내기를 선택하면 선택한 외부 앱에 사본이 전달됩니다. 이후 보관·삭제에는 해당 앱의 정책이 적용됩니다.

보관과 삭제

개인 기록
앱에서 직접 삭제하거나 앱 데이터를 삭제할 때까지 기기에 보관합니다. 앱 삭제·데이터 삭제로 기록이 사라질 수 있습니다. Android 또는 기기 제조사의 백업 설정에 따라 별도의 백업·이전 사본이 존재할 수 있습니다.
계정과 친구
계정·프로필·규칙 동의 정보는 계정 삭제 시까지 보관합니다. 친구 관계·차단 상태는 앱에서 변경한 내용을 반영하며 계정 삭제 시 정리합니다.
편지 원본
정상적으로 전달된 편지에는 자동 만료를 적용하지 않습니다. 친구 삭제·차단 후에도 남습니다. 발신자가 탈퇴하거나 위반으로 운영 삭제되면 서버 원본을 제거하고 상대에게 삭제 상태를 표시합니다.
미완료 업로드
접수되지 않은 업로드는 예약 후 24시간이 지나면 정리 대상이 됩니다. 접수 후 남은 업로드 사본도 정리합니다.
신고 자료
신고 검토·이의 제기 처리·위반 재발 방지를 위해 신고 자료와 열람 기록을 신고 접수일부터 90일간 보관한 뒤 정리합니다. 관련 위반 이미지 해시는 해당 신고의 만료일을 따릅니다. 계정 삭제 후에도 이 기간을 적용합니다.
계정 삭제 표식
완료된 계정 삭제를 재시도하거나 오래된 요청이 실행되는 것을 막는 최소 표식은 24시간 보관합니다.
요청 제한 기록
과도한 요청 방지용 기록은 마지막 갱신 후 24시간이 지나면 정리 대상이 됩니다.

삭제 대상은 서비스에서 접근을 차단한 뒤 파일과 데이터베이스의 삭제 절차로 정리합니다. 오프라인 기기의 편지 사본은 다시 연결할 때 삭제 상태가 반영됩니다. 이미 외부로 내보낸 사본은 회수할 수 없습니다.

Firebase의 공개 정책에 따르면 Authentication의 IP 로그는 수 주간 보관하며, 그 밖의 인증 정보는 제공자에게 계정 삭제를 요청한 뒤 운영 시스템과 백업에서 180일 이내에 삭제합니다. 이는 NooKeep의 계정 삭제 완료 표식 24시간과 별개의 기간입니다.

권리와 문의

앱의 우체통 → 우체통 설정 → 계정 삭제에서 탈퇴할 수 있습니다. 인증 계정·프로필·친구 관계와 보낸 편지 원본을 삭제합니다. 상대가 보낸 원본은 상대의 기록으로 남을 수 있으며 탈퇴자의 식별 정보는 익명화합니다. 기기의 개인 상자와 스티커는 계정과 별개이므로 남습니다.

앱을 이용할 수 없어도 dev.utact@gmail.com로 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 계정 소유 확인에 필요한 최소 정보만 확인하고 처리 결과를 안내합니다. 자세한 방법은 계정 삭제 안내를 참고하세요.

방침이 바뀌면 변경 내용과 시행일을 이 페이지에 게시합니다.

권한과 보안

카메라 권한은 촬영에, 알림 권한은 허용한 기록 알림에 사용합니다. 사진을 고를 때는 시스템 선택 화면에서 사용자가 고른 항목에 접근합니다. 선택 권한을 거부해도 해당 기능을 제외한 개인 기록은 사용할 수 있습니다.

서버 통신은 암호화된 연결을 사용하고 계정별 접근 권한과 운영자 권한을 구분합니다. 로그에는 편지 본문·사진·닉네임·인증 토큰을 의도적으로 기록하지 않습니다. 필요한 인원만 신고 자료를 열람하도록 제한합니다.
